How this works

Our Logistic Regression model was trained on RNA-seq data from The Cancer Genome Atlas (TCGA), achieving 96.2% accuracy across 32 cancer types. Each gene was ranked using ANOVA F-tests in a one-vs-rest framework — measuring how strongly a gene's expression differs in each cancer type vs all others. The higher the F-score, the more diagnostic that gene is. Gene annotations were retrieved from the DAVID Bioinformatics database.
